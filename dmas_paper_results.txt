4.1 Dataset and Simulation Setup

To evaluate the DMAS pipeline at scale, a synthetic dataset of 2,988
data points was generated, empirically grounded in official post-disaster
reports from the Lagos State flood event of December 2024. The dataset
was distributed across eight (8) Local Government Areas (LGAs) that
experienced flooding, consistent with the IOM DTM/NEMA Joint Assessment
Report of 30 December 2024, which documented 275,621 displaced persons
across 48,403 households (IOM DTM/NEMA, 2024). Meteorological parameters
were sourced from the NIMET Bulletin for December 2024, recording a
peak rainfall intensity of 48.7 mm/h, a 24-hour accumulation of
187.2 mm, and a tidal surge of 122 cm above baseline.

The dataset comprised:
  • 2,000 simulated social media posts (tweets)
  • 590  simulated IoT flood sensor readings
  • 398  simulated 311/LASEMA emergency call records
  ─────────────────────────────────────────
  TOTAL: 2,988 synthetic data points

Of the 2,000 social media posts, 1,170 (58.5%) were classified as
genuine distress signals, 345 (17.2%) as misinformation, and 485
(24.2%) as noise or irrelevant content. This distribution reflects
documented patterns in social media during urban flood events, where
a significant proportion of posts contain non-actionable or misleading
information (Imran et al., 2015).

The simulation was executed on Ubuntu 22.04 LTS using Python 3.10+
with an asyncio concurrency framework. All results are reproducible
via a fixed random seed (seed=42).

4.3 Layer 2 — Cross-Modal Verification Agent

The Credibility Score Sc(r) was computed for each LGA using the
Weighted Convergence Algorithm (WCA):

        Sc(r) = Σ(wi · ki) / Σ(wi)

where:
  k_phys = IoT sensor alert rate + flood depth index  (weight w=0.90)
  k_gov  = severity-weighted emergency call score     (weight w=0.75)
  k_soc  = engagement-weighted distress tweet ratio   (weight w=0.40)

Sc scores were classified against two gate thresholds:
  TRUST gate       : Sc ≥ 0.85  → forwarded to synthesis pipeline
  UNCERTAINTY gate : 0.50 ≤ Sc < 0.85 → forwarded with uncertainty flag
  SUPPRESSED gate  : Sc < 0.50  → blocked from pipeline

The system achieves a high recall of 95.8%, indicating that DMAS
successfully captures the vast majority of genuine flood distress
signals. The precision of 65.0% reflects the challenge of suppressing
misinformation in a system deliberately biased toward high sensitivity
— a necessary design trade-off in life-critical emergency systems
where missing a genuine distress signal (false negative) carries a
higher cost than forwarding an uncertain report (false positive).
This aligns with established principles in disaster informatics
where recall is prioritised over precision (Imran et al., 2015;
Castillo et al., 2016).

The F1-score of 0.7745 represents a robust balance given the dataset
characteristics and the binary gate architecture. Future work will
explore dynamic threshold tuning to improve specificity without
compromising recall.

4.5 Layer 3 — Geospatial Synthesis Agent (CDSS)

The Compound Disaster Severity Score (CDSS) was computed for each LGA:

        CDSS(j,t) = 0.5·S + 0.3·V + 0.2·HI

where S is the credibility score, V is the vulnerability index
(sourced from IOM DTM/NEMA population exposure data), and HI is the
Hazard Intensity index derived from IoT flood depth readings, adjusted
for infrastructure status and rainfall intensity.

Five of the eight evaluated LGAs were classified as CATASTROPHIC,
consistent with the IOM DTM/NEMA ground truth which reported severe
displacement across five of the eight zones. Ajegunle ranked highest
(CDSS = 0.914), driven by its high vulnerability index (V = 0.920),
extreme flood depth (1.85 m), and critical infrastructure status —
factors corroborated by field reports documenting 52,440 displaced
persons in the Ajeromi-Ifelodun LGA. Victoria Island received the
lowest CDSS (0.399), consistent with its comparatively low flood
depth (0.45 m) and lower population exposure (5,130 persons).

"The experimental dataset was generated synthetically to simulate

including LGA-level flood depths, population exposure figures,

grounded in official post-event reports: the IOM DTM/NEMA Joint

(2024). This approach is consistent with established simulation

real-time API from the Lagos State Emergency Management Agency (LASEMA)
and restricted access to large-scale Twitter/X streaming data in the
Nigerian research context. The synthetic dataset of 2,988 data points
was used to stress-test the DMAS verification and prioritization
pipeline across all eight affected LGAs, enabling reproducible
evaluation of system performance."
